# Scout de Vôlei

Scout manual de vôlei com o vídeo do YouTube na mesma tela.

**Abrir:** https://arthurlumertzg.github.io/scout-volei/

- Cole o link do YouTube, toque no atleta e depois na ação.
- Cada registro guarda o tempo do vídeo; no Histórico, ▶ volta ao lance.
- Dados ficam no navegador do aparelho. Exporte CSV ou salve o backup (.json) na aba Elenco.
